Ever had a great run going and then you died?
This mod is here to salvage it -- you can replay the floor you were on, instead of having to start a new seed.

Your restart will put you back in exactly the same state you were in, including:
- Inventory (including stacked items, gold, reloaded ammo, and holstered items)
- Health (including max health and cursed hearts)
- Combo/Multiplier (or "groove")
- Ring/Shrine state (e.g. Ring of War or Shrine of Space)
- Randomness (enemy movements, enemy spawns, item spawns, transmute effects)
- Trapdoor behavior (crates dropped will be remembered, ambushes can be replayed)
